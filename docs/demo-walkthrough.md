# Demo Walkthrough

1. Start stack.
2. Create teacher account.
3. Create class and skills.
4. Open class registration channel and copy class code for students (optional pre-registration).
5. Ingest content and generate candidates.
6. Approve candidates and publish quiz.
7. Start session and share PIN/QR from host screen.
8. Students join and answer (with optional team names for group mode).
9. Observe host live metrics (`active/joined`, participation, wrong-option cluster, team leaderboard) updating from `dashboard_metrics`.
10. Trigger assist card in host view when misconception threshold is exceeded.
11. End session and open report.
12. Review support groups, remediation pack, deep insights, and student passports.
